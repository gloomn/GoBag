### Requirements
* Developed for Windows 10 and Windows 11 64-bit.
* Uses C# .NET Framework version 4.7.2.
* Uses C# version 7.3.

---
### Nuget Package
* System.Data.SQLite V1.0.118(used for local database).

---
### 사용방법(How to use)
* Download the compressed folder from the Release tab, extract it, and run it directly.
* To add an item: click the Add button, fill in the textboxes, then click Save.
* To delete an item: select a row in the DataGridView, then click Delete.
* To edit an item: select a row in the DataGridView, modify the textbox content, then click Save.
* Calculates expiration dates for this year, next year, and the year after next, and notifies expiration status.
